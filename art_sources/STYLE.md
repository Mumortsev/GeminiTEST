# Фотореалистичный каталог 1.3

Визуальный стиль утверждён пользователем в диалоге: предметные фотореалистичные изображения, мягкое студийное освещение, тёплый светлый фон, заметные особенности ткани и кроя. Все предметы целиком в кадре, без подписей, брендов, людей и декоративных предметов. Текст выводится отдельными Android-компонентами.

Это **сгенерированные иллюстрации**, не снимки реальных товаров и не изображения из интернет-магазинов. Они подготовлены заранее средствами генерации изображений в рабочем диалоге. Приложение не обращается к сервисам ИИ и не передаёт им данные пользователя.

Готовые 94 изображения занимают 2 962 382 байта (около 2,96 МБ) в 60 WebP-ресурсах.

`catalog.json` содержит стабильный ID, русское название, описание для подготовки изображения и параметры одежды. `manifest.json` содержит размеры, вес и контрольные суммы готовых ресурсов. `style-reference.webp` — утверждённый образец, не включённый в APK.

Для обычной сборки нужны только включённые в Git WebP-ресурсы `app/src/main/res/drawable-nodpi/art_*.webp`. Часть изображений хранится отдельными файлами, часть — в листах 3×2: Android декодирует только нужную прямоугольную область. В интерфейсе показывается одна вещь, а не общий лист. Схема размещения — layout.json. PNG-оригиналы не требуются и не добавляются в репозиторий, чтобы не раздувать его. При наличии оригиналов повторный экспорт:

```sh
python tools/prepare_photos.py --sources /path/to/png-originals
```

Имена отдельных оригиналов соответствуют ID (`body_short.png`, `winter_suit.png`); листы называются `photo_sheet_01.png` и т. д. Полный перечень — в layout.json. Нужен ImageMagick (`magick`). Экспорт сохраняет соотношение сторон, уменьшает избыточное разрешение отдельных снимков до длинной стороны 768 px, листов — до 1536 px (ячейка типового листа 512×512 px), удаляет метаданные и кодирует WebP с качеством 90. Это сжатие с потерями. Идентификаторы совпадают с предыдущими версиями: сохранённые гардеробы, комплекты и пользовательские фотографии не меняются.

Генерация изображений не детерминирована: повтор того же описания может дать другой результат. Контрольные суммы фиксируют именно включённые файлы; они не обещают воспроизводимость генерации по тексту.
