# Каталог гардероба 0–3 лет

Перед реализацией разделены основа (верх/низ/цельная одежда), средний и наружный слои, головные уборы, носки, обувь, рукавички и принадлежности коляски. Обувь для ходьбы не предлагается младенцам по умолчанию; размер, материал, слой и конкретное изделие важнее названия сезона. Каталог охватывает основные типы, но не объявляется исчерпывающим: родитель может добавить свою вещь.

С версии 1.3 изображения — фотореалистичные иллюстрации в WebP. Они заранее сгенерированы в утверждённом предметном стиле, а не сняты с реальных товаров. Формы одежды и материалы различаются, подписи выводит Compose. Все картинки встроены для офлайн-работы; внутри приложения нет генерации изображений и ИИ-API. Перечень, описания и происхождение — art_sources/. Обновление метаданных: tools/generate_catalog.py; экспорт готовых PNG в WebP: tools/prepare_photos.py. Старые схематичные VectorDrawable удалены.
